# VEM 弦乐引擎 · 数据、许可与交付说明

> 本文件对应开发计划 §9（数据与许可证）与 M6（体积/CPU/许可报告）。
> 结论先行：**代码可以按 Apache-2.0 交付；参考实现的素材与源码一律不随交付走。**

---

## 1. 代码许可

| 内容 | 许可 | 说明 |
|---|---|---|
| `vem/src/**`、`vem/tests/**`、`vem/tools/**`、`scripts/**` | **Apache-2.0** | 独立实现：算法思路来自公开描述（谱激励 + 谐波阻尼 + 周期重合成），并用参考实现做**行为对照**，没有逐行翻译 |
| `vem/reference/` | **LGPL-2.1**（上游 VEM） | **gitignore**，由 `vem/fetch-reference.ps1` 按固定 commit 拉取；只在开发期对拍，不参与交付 |
| `vem/reference-overrides/**` | Apache-2.0 | 我们自写的两个渲染 bin + 公共 WAV 工具；对上游的改动由脚本字符串注入（种子 / `VEM_BODY` / `VEM_NOISE`），仓库里**不含**上游源码拷贝 |
| `web/`（DX7 baseline） | 沿用 `../261115-daw` 的许可与来源说明 | `msfa.wasm` 来自该仓库的构建产物，本仓库只做 baseline 与对拍 |

本仓库的 `LICENSE` 目前是 Apache-2.0 的指路文件；正式对外发布前补全标准全文即可。

## 2. 数据（最重要）

| 数据 | 来源 | 是否入库 | 是否交付 |
|---|---|---|---|
| `vem/reference/synth/src/data/*.flac`（琴体 IR、弓噪） | VEM 作者录制，LGPL-2.1 | 否（reference 目录） | **否** |
| `out/vem-data/*.bin`、`web/data/vem/*.bin` | `gen-data` 从上面 FLAC 转出的 `VEMD` 容器 | 否（gitignore） | **否** |
| `web/data/notes.bin` / `tracks.json` / `patches.bin` / `mix.json` | 我们自己的 DX7 工程导出 | 是 | 是（项目素材） |

**开发期的对拍充分依赖参考素材，但交付版本必须把 IR 与弓噪换掉**（计划 §1.5：数据 ≤ 80 KB）：

1. **琴体 IR**：自录 4 件乐器（每件 0.2–0.4 s）或合成（共振峰 + 指数衰减），
   仍用 `VEMD` 容器与 `vem_set_patch` 装载，引擎无需改代码；
2. **弓噪**：优先用**合成版**（`noise.rs` 已留 1=采样 / 2=合成 的开关），
   或自录 1–2 s 的循环，量化到 16-bit 后约 100–200 KB；若必须 ≤80 KB，可降到 8-bit/单声道；
3. 音频亏损用 `band-energy` / `vem-metrics` 复核，目标与参考素材版本的三段频响差 ≤ 2 dB。

## 3. 体积报告

| 项 | 数值 |
|---|---|
| `vem/wasm/vem.wasm` | **87.2 KB**（89,280 B），imports **0** |
| 计划预算 | ≤ 120 KB ✅ |

| 素材 | 不在 wasm 内（运行时 `vem_set_patch` 装载） |

## 4. CPU 报告

实测环境：Windows / Node 22（V8 wasm），48 kHz，**1 voice**，
包络 = melody 预设，数据 = 完整琴体 IR（0.37 s）+ 5.21 s 弓噪：

| 版本 | 实时占比 |
|---|---|
| 参考结构的分块卷积（初版） | 17.3% |
| 2 的幂 radix-2 专用 FFT | 4.1% |
| \+ 实数 FFT | 3.3% |
| \+ 热循环去掉边界检查 | **2.80%** ✅（目标 ≤3%） |

整曲 worklet（9 轨 DX7 + VEM CH3）在 Node 假环境里约 17.7% 实时；
浏览器实测（Chrome）ready @48 kHz、4824 事件、播放推进、电平表 11%。

## 5. v2 决策（遗留）

- `no_std` + 自写更小 FFT（当前 87 KB 已达标，暂不必要）；
- 8-bit 量化素材 / 合成弓噪（交付前必做，见 §2）；
- 多声部（`vem_set_polyphonic(1)` 已实现，但未做多轨验收）。
